# Student Records and Marks Analyzer

## Project Overview

The Student Records and Marks Analyzer is a Python-based command-line application designed to manage student information and academic performance.

The program collects student details and subject marks, calculates total marks and average percentages, assigns result categories, and generates student performance reports.

It uses Python data structures such as lists, tuples, sets, and dictionaries to store and analyze student records.

## Features

- Add multiple student records.
- Store student IDs and personal details.
- Enter marks for multiple subjects.
- Validate student IDs and marks.
- Calculate total marks and average.
- Assign result categories (Distinction, Pass, Fail).
- Display complete student reports.
- Search student records using student ID.
- Update student marks.
- Find unique subjects.
- Perform set operations.
- Display class performance summaries.
- Calculate highest and lowest student averages.


2. Open the project folder:

```bash

```

3. Run the Python program:
